# Favicon export

The portfolio favicon reduces the identity to three existing visual signals:

- Swedish yellow for the portfolio's editorial chapters.
- Ink black for engineering clarity.
- One blue node for logic and connected systems.

The abstract `D` uses broad geometry and a generous counter so it stays recognizable at 16 × 16 pixels. Final browser assets are deterministic exports from the same 64-unit construction used by `favicon.svg`.

Exports:

- `favicon-16.png` — browser fallback.
- `favicon-32.png` — high-density browser fallback.
- `apple-touch-icon.png` — 180 × 180 Apple home-screen icon.
- `favicon-192.png` and `favicon-512.png` — web-app manifest icons.

Creative provenance: the production mark was art-directed from a generated single-icon exploration, then reduced to the portfolio's exact color tokens and rebuilt as resolution-independent geometry for reliable small-size rendering.
